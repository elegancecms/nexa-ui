# GitHub Repository Oluşturma Adımları

## 🚀 Adım 1: GitHub'da Repository Oluşturun

1. **GitHub'a gidin:** https://github.com/new

2. **Repository bilgilerini doldurun:**
   - **Repository name:** `nexa-ui`
   - **Description:** `Lightweight, zero-dependency React UI component library`
   - **Visibility:** ✅ **Public** (önerilen)
   - ❌ **Initialize this repository with:** Hiçbirini işaretlemeyin (README, .gitignore, license)
   - **Create repository** butonuna tıklayın

## ✅ Adım 2: Repository Oluşturulduktan Sonra

Repository oluşturulduktan sonra GitHub size şu komutları gösterecek:

```bash
git remote add origin https://github.com/elegancecms/nexa-ui.git
git branch -M developer
git push -u origin developer
```

**AMA** önce local'de commit yapmamız gerekiyor!

## 📝 Adım 3: Local'de Commit Yapın

Repository oluşturduktan sonra bana haber verin, şu komutları çalıştıracağız:

```bash
# 1. Tüm dosyaları ekle
git add .

# 2. Commit yap
git commit -m "Initial commit: @khaimerax/nexa-ui"

# 3. Remote ekle
git remote add origin https://github.com/elegancecms/nexa-ui.git

# 4. Branch'i developer yap
git branch -M developer

# 5. Push yap
git push -u origin developer
```

---

**Şimdi yapmanız gereken:** GitHub'da repository oluşturun, sonra bana haber verin!
