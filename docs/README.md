# @khaimerax/nexa-ui Documentation

This is the documentation site for @khaimerax/nexa-ui, built with VitePress.

## Development

```bash
cd docs
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The site can be deployed to:
- **Vercel** (recommended)
- **Netlify**
- **GitHub Pages**
- **Cloudflare Pages**

### Vercel Deployment

1. Connect your GitHub repository
2. Set build command: `cd docs && npm install && npm run build`
3. Set output directory: `docs/.vitepress/dist`
4. Deploy!
